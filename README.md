# PAUteca

Exámenes de selectividad (PAU) de Andalucía resueltos paso a paso: Matemáticas Aplicadas a las CCSS, Matemáticas II, Física, Química y Ciencias Generales.

- `index.html`, `app.js`, `estilos.css`: la aplicación.
- `datos/`: todo el contenido (ver `datos/LEEME.md`).
- `manifest.webmanifest`, `sw.js` e iconos: app instalable (PWA).

Para publicar una actualización basta con sustituir los archivos y subir el número de versión de `sw.js`.
